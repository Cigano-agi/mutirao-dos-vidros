# Como contribuir

1. Rode `npm run demo` e reproduza o fluxo com um papel de demonstração.
2. Abra uma issue com o papel usado, os passos, o resultado observado e o esperado. Use exemplos inventados.
3. Para propor uma correção, faça um fork, crie uma branch e abra um pull request com o motivo da mudança e os testes executados.
4. Rode `npm test` para mudanças na API. Para mudanças de interface, rode também `npm run test:ui` ou descreva o caminho que verificou no navegador.

Ao anexar algo a uma issue ou pull request, use somente dados fictícios. Mantenha nomes, telefones, endereços, coordenadas residenciais, fotos de imóveis, exportações, logs de atendimento e códigos de acesso reais fora do GitHub. Use os registros de demonstração em `demo.mjs` como referência.
